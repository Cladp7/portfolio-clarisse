# Portfolio de Clarisse Dupont – thème WordPress sur mesure

Thème enfant de **Kadence**, codé à la main pour mon portfolio de web designer UI/UX en formation.

**Voir le site** : https://clarisse-dupont.netlify.app (version anglaise : https://clarisse-dupont.netlify.app/en/)

## Ce que contient le thème

- **Un type de contenu « projet »** avec des champs ACF Pro (contexte, objectif, démarche, galerie, apprentissages)
- **Des modèles sur mesure** : `archive-projet.php`, `single-projet.php`, `page-mon-parcours.php`, `page-contact.php`, `template-parts/`
- **Une version anglaise sans extension** (`inc/langue.php`) : adresses `/en/…`, traductions rangées dans un champ du projet, liens et textes traduits automatiquement
- **Un design system en variables CSS** (`style.css`) : échelle d'espacement 4-8-12-16-24-32-48-64-96-128, contrastes vérifiés (4,5:1 minimum), polices locales
- **Accessibilité** : textes alternatifs FR/EN, nom accessible pour le logo, zones de toucher de 48 px, repère du lien actif qui ne dépend pas que de la couleur
